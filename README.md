# 🌸 Blog Cursos Tulipa Cosméticos - V2 (Versão Moderna)

Uma versão totalmente redesenhada, ultra-moderna e de alta conversão para o portal de cursos da **Tulipa Cosméticos**.

## ✨ Principais Diferenciais
- **Design Premium**: Glassmorphism, gradientes elegantes, tipografia refinada e cards com microinterações.
- **Alta Conversão**: Barra de contagem regressiva com oferta por tempo limitado, botão flutuante de WhatsApp e CTAs estratégicos.
- **Next.js 15 + React 19**: Performance de ponta, App Router e suporte a SEO otimizado.
- **Framer Motion + Tailwind CSS**: Animações fluidas e responsividade perfeita em desktop, tablet e mobile.
- **Categorias e Filtros**: Navegação intuitiva entre áreas como Estética Facial, Corporal, Cosmetologia, Harmonização e Gestão de Clínicas.

## 🚀 Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Build de produção
npm run build
```
